AutoGraphicsFind

A portable Windows utility that detects NVIDIA or AMD graphics hardware and installs the matching official driver.

Download

Feature List

NVIDIA

  • Autodetects NVIDIA graphics hardware.
  • Downloads official Game Ready or Studio drivers.
  • Provides a clean installation option (excludes the NVIDIA App).
  • Installs supplementary NVIDIA HD Audio and USB-C drivers where applicable.

AMD

  • Autodetects AMD graphics hardware.
  • Downloads official AMD display drivers directly from the vendor.
Windows 10 and 11. No installer required.
